# G LA DALLE — Homepage Concept Redesign

A modern neo-retro UI/UX concept redesign for **G La Dalle**, built with a lightweight frontend stack.

## Live Demo
👉 [https://onanavitaldev.github.io/gladalle/](https://onanavitaldev.github.io/gladalle/)

## Features
- **Interactive Burger Carousel:** Focus-central showcase with rotating stickers, ingredients, and `Single / Double / Triple` pricing.
- **Product Detail Modal:** Full recipe breakdown, nutrition facts, allergens, size/combo selection, and live price calculation.
- **Filterable Menu:** Instant category filtering (`All`, `Burgers`, `Dalle du Moment`, `Frites & Sides`, `Desserts`).
- **Store Locator:** Quick search across locations with late-night hours and order modal options.

## Tech Stack
- **HTML5 & Tailwind CSS**
- **Vue.js 3** (via CDN)
- **GSAP** (animations & transitions)
- **Lucide Icons**
